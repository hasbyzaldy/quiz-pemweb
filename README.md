# Daily Tasks - To-Do List React.js

Aplikasi To-Do List untuk Kuis Praktikum Pengembangan Frontend.

## Fitur
- Menampilkan daftar tugas dari data dummy.
- Melihat detail tugas.
- Menambahkan tugas.
- Memperbarui tugas.
- Menghapus tugas dengan konfirmasi.
- Mengelola perubahan menggunakan React State.

## Atribut Data
Setiap tugas memiliki `id`, `title`, `description`, `priority`, `deadline`, dan `status`.

## Teknologi
React.js, Vite, JavaScript, CSS, dan Lucide React.

## Cara Menjalankan
```bash
npm install
npm run dev
```

Buka alamat localhost yang ditampilkan oleh Vite.
